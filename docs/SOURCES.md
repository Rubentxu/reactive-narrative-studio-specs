## Design inspiration
The project deliberately carries forward selected SDDK ideas:
- evidence-driven gates;
- project-local isolation;
- next-action ergonomics for agents;
- deterministic verification;
- receipts;
- rebuildable projections;
- architecture emerging from measured pain.

It explicitly does NOT port the full SDDK software-development workflow.
