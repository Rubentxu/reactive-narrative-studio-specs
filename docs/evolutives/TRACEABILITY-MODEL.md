# Traceability Model

```text
Milestone
  └─ Requirement
      ├─ Specification
      ├─ ADR
      └─ Scenario
          ├─ Driver
          ├─ Oracle
          └─ Evidence
              └─ Verdict
```

IDs: `REQ-*`, `ADR-*`, `UAT-*`, `SCN-*`, `ORC-*`, `RUN-*`, `WVR-*`.

Requirement states: UNMAPPED, MAPPED, VERIFIED, PARTIALLY_VERIFIED, FAILED, HUMAN_ACCEPTANCE, NOT_AUTOMATABLE, OBSOLETE.

`done` se deriva del Audit Gate; no se asigna por texto libre.
