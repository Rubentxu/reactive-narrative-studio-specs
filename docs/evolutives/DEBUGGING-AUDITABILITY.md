# Debugging & Auditability

Todo FAIL debe responder: commit, requisito, UAT, scenario, step, oracle, expected, actual, evidence y cómo reproducirlo.

Error classes recomendadas: PRODUCT_DEFECT, HARNESS_DEFECT, ENVIRONMENT_DEFECT, PROVIDER_DEFECT, FLAKY, HUMAN_REJECTED, UNSUPPORTED.

Reproducibility fingerprint: commit SHA + tool versions + scenario hash + fixture hash + environment fingerprint.
