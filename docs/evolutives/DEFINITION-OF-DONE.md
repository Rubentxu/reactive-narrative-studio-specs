# Definition of Done

## Slice Done
Compila, contracts/tests adecuados, docs actualizadas.

## Milestone Done
Además: requirements trazados, UAT ejecutados, evidence ligada a SHA, cero FAIL/UNMAPPED obligatorios, waivers explícitos y audit report reproducible en CI.

## Release Done
Además: clean tree, tag/commit auditado, evidence retenida y tool/dependency versions registradas.
