# UAT-M17-01 — Write-capable Control Plane: decision-command records

## Objective

Verify that the Control Plane can emit outbound decision-command records
(approve / reject / comment / regeneration request) from the `/decisions` view:
the loaded cp-decisions projection is listed, row actions prefill the composer,
records are validated against `specs/cp-commands.schema.json` BEFORE write, and
the write lands on the filesystem (File System Access directory when available,
download fallback otherwise) — no persistent backend, no network, no store
mutation.

## Scope

- In: `/decisions` view, CommandComposer validation gating, FSA→download sink
  chain, cp-commands schema conformance of the emitted record, prefill
  discipline, store round-trip no-op.
- Out: applying commands back into a project snapshot (external workflow),
  real image regeneration, multi-user flows, directory-picker UX in headless.

## Preconditions

- Control Plane built and served (preview server).
- Golden snapshot `golden/control-plane/snapshot-valid/**` available (contains
  `projections/cp-decisions.json`: silver-key accepted, nora-arc pending,
  iron-door rejected).

## Scenarios

### SCN-M17-01-001 — Command records from the decisions view (executable)

1. Load the golden snapshot; navigate `/decisions`.
2. Probe: 3 decision rows with statuses accepted / pending / rejected.
3. Click `approve` on `nora-arc`; probe prefill: kind=approve,
   targetRef=`Character:demo/nora`, subjectDecision=`nora-arc`.
4. Fill rationale, submit → download artifact `decisions.approve.command.json`;
   the record conforms to cp-commands.schema.json and carries the declared
   fields (single-line JSON, id/createdAt non-semantic).
5. In the standalone composer, compose `regenerate` for
   `Scene:demo/scene-silver-key` with reason + scope=scene → download artifact
   `decisions.regenerate.command.json`; same conformance + field assertions.

## Acceptance criteria

| # | Criterion | Evidence |
| --- | --- | --- |
| AC-1 | Decisions listed with id/action/targetRef/status | probe-decisions oracle |
| AC-2 | Row action prefills composer (kind/targetRef/subjectDecision) | probe-prefill oracle |
| AC-3 | Emitted approve record validates against cp-commands schema | schema oracle ×2 |
| AC-4 | Emitted records carry command/targetRef/origin/payload exactly | jsonl-entry oracle ×2 (id/createdAt ignored, non-semantic) |
| AC-5 | Write lands via download fallback in headless (FSA preferred in real browsers) | submit artifacts present |
| AC-6 | Invalid records never written | unit tests (validation gating) |
| AC-7 | Store round-trip no-op on route mount; no fetch/IndexedDB in feature | unit tests (decisions-view, purity) |

## Requirements coverage

- REQ-M17-6, 7: this scenario (functional level).
