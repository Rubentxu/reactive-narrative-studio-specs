# UAT-M10-07 — Recipe contract executable verification (creation recipes)

## Given
The bundled `recipes/middle-grade-illustrated/` recipe, the local Python CLI (`narrative-cli`) and shared core (`narrative_recipes`), the wizard sources under `control-plane/src/features/recipes/`, and the studio build.

## When
The recipe contract is exercised end-to-end: schema validation of the bundled recipe, plan generation with DEFAULT parameters, the Python test batteries, the script-execution / no-write / no-fetch security greps, and a real browser visit to `/create`.

## Then
The plan renders with the declared defaults applied (audience `profile-middle-grade-10-11`, imagePolicy `local_preferred`, genre `fantasy`, outputLanguage `es-ES`, skeleton ≥ 12 entries); no script-execution vector exists in recipe code paths; the wizard performs no writes to the Control Plane projection state and no fetches; `/create` renders cleanly.

## Pass
- `tools/validate-recipes/validate.py recipes/middle-grade-illustrated` exits 0 ("All checks passed").
- `narrative plan --recipe middle-grade-illustrated` with only title+projectId produces: `manifest.audience.profile == profile-middle-grade-10-11`, `imagePolicy == local_preferred`, `genre == fantasy`, `outputLanguage == es-ES`, `len(skeleton) >= 12`.
- `pytest tools/narrative_recipes/tests tools/narrative-cli/tests` passes entirely.
- `grep -rE 'eval\(|exec\(|subprocess|os\.system'` over `control-plane/src/features/recipes` + both Python packages finds NOTHING (zero script-execution vectors).
- `grep -nE 'fetch\(|useProjectionStore'` over `control-plane/src/features/recipes` finds NOTHING (no CP state mutation, no outbound calls).
- `/create` renders in the browser with zero page errors and zero console errors.

## Does not prove
- Visual wizard UX quality beyond renderability (form interactions covered by component tests).
- Real image generation or provider enablement (REQ-CR-12 explicitly excludes it).
- CI pipeline execution itself (the gates are asserted locally here; CI runs the same batteries on push).
